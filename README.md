# astrbot_plugin_tts_send

让 AstrBot 通过 `/角色说 文本` 调用本机 `live-stream-chatbot` 中间件合成音频，并把语音发送到当前群聊。

中间件 TTS 后端已切换为 **Genie-TTS**（ONNX CPU，`tts.backend: "genie"`），`/synthesize` 接口契约不变，本插件走中间件统一串行队列，对后端无感知；同时接入了 Genie 的零成本情绪能力（情绪 = 换参考音频）。

## 使用

群聊里带上唤醒前缀 `/` 发送：

```text
/樱羽艾玛说 你好
```

也可以使用：

```text
/tts 樱羽艾玛说 你好
/语音 樱羽艾玛说 你好
```

中间件会根据文本开头的“角色名说”自动匹配 `config/config.json` 中的角色；未匹配时使用默认角色。

> **权限提醒**：插件默认**仅管理员可用**。要让群里其他成员也能用，需在配置中开启「额外允许非管理员调用」。

### 命令前缀说明（v1.4.0 起，# 写法已移除）

AstrBot 在把消息交给插件之前，会**先把唤醒前缀 `/` 从消息文本中剥掉**（见 `core/pipeline/waking_check/stage.py`）。因此：

| 你实际发送 | 插件收到的 | 结果 |
| --- | --- | --- |
| `/樱羽艾玛说 你好` | `樱羽艾玛说 你好` | ✅ 正常合成 |
| `/tts 樱羽艾玛说 你好` | `tts 樱羽艾玛说 你好` | ✅ 正常合成（`/tts`、`/语音` 整体剥掉 `/` 后仍能识别） |
| `#樱羽艾玛说 你好` | `#樱羽艾玛说 你好` | ❌ v1.4.0 起不再支持 |

所以插件同时识别两种形态：**带 `/` 的原始写法**，以及**被剥掉 `/` 之后的写法**（这也是群里实际会抵达插件的那一种）。

补充：若 `#` 消息没有被 `/` 唤醒，AstrBot 会在进入插件前就终止事件，所以 `#` 写法在恢复唤醒词后本就不可用。

### 情绪标签（v1.1.0 新增）

Genie 每个角色支持 9 种情绪，命令里加 `[情绪]` 即可指定，支持中文/英文两种写法，位置可以在角色名后或文本开头：

```text
/樱羽艾玛[开心]说 你好
/tts [happy] 樱羽艾玛说 你好
/语音 二阶堂希罗说 【害羞】诶嘿嘿
语音 [emo:angry] 你给我进来
```

可用情绪：`neutral`(平静) / `happy`(开心) / `question`(疑问) / `tender`(温柔) / `angry`(生气) / `sad`(难过) / `shy`(害羞) / `cold`(高冷) / `surprised`(惊讶)。

- 不带情绪标签时，中间件按文本内容自动分类情绪。
- 方括号内容不是已知情绪时原样保留在文本里，不影响普通使用。
- 角色缺某情绪时（如 诗歌剧/聪明露娜 仅 neutral）由中间件自动回退到 neutral。

### 权限与频控（v1.2.0 新增，v1.3.0 简化为单一权限开关）

非 TTS 命令完全不受影响：只有识别为 TTS 命令的消息才会进入下面的判定，普通聊天不会因此被拦截或消耗配额。

判定顺序（先命中先返回，命中即终止本次消息的后续插件/LLM 处理）：

1. **是管理员**（在 AstrBot 全局 `admins_id` 名单内，`/op <id>` 授权）→ 始终放行，不受冷却/限额限制，也不占用计数；
2. `allow_non_admin` 关闭（默认）→ 非管理员收到「仅管理员」提示；
3. `allow_non_admin` 开启后，非管理员继续走频控：
   - 冷却（默认 3 秒）：距上次成功调用不足 3 秒 → 返回冷却提示（含剩余秒数）；
   - 限额（默认 1 分钟 10 句）：窗口内已用满 → 返回限额提示（含剩余秒数）；
4. 通过 → 正常合成并发送。

要点：

- **权限只有一个开关**：默认仅管理员；打开 `allow_non_admin` 即放开给其他用户，此时冷却/限额才开始起作用。
- **计数维度为「用户全局」**：同一个用户 ID 在所有群聊与私聊之间共享冷却与配额，换群不能绕过。
- **只有放行的调用才计时**：被拒绝的请求不会刷新冷却、不占用配额。
- **冷却/限额在合成之前计数**：这是为保护中间件串行 TTS 队列；合成失败也计一次。
- 计数保存在插件内存中，插件重载或 AstrBot 重启后清零。
- 所有数字与提示文案都可在 WebUI 配置中单独修改；提示文案支持占位符 `{remaining}`（剩余秒数，向上取整）、`{limit}`、`{window}`、`{cooldown}`。占位符写错时自动回退默认文案，不会报错。
- 想「完全放开且不限速」：开启 `allow_non_admin`，并把 `non_admin_cooldown_enabled` 与 `non_admin_limit_enabled` 都关掉。

> 该命令使用高优先级正则直接拦截，发送语音后会终止本次消息的后续插件/LLM 处理，避免被记忆等插件当作普通聊天消息处理。权限/频控拦截时同样会终止事件——否则命令文本会漏给 LLM 当成普通聊天。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `middleware_url` | `http://host.docker.internal:8899/synthesize` | live-stream-chatbot 的合成接口（Docker 内访问宿主机；非 Docker 可改为 `http://127.0.0.1:8899/synthesize`） |
| `timeout` | `300000` | TTS 请求超时（毫秒），Genie 冷启动（自动拉起 server + 首角色加载）较慢，建议保持较大值 |
| `max_text_length` | `120` | 最大合成文本长度，超出会截断 |
| `send_error_message` | `true` | 合成失败时是否在群里提示错误 |
| `allow_non_admin` | `false` | **额外允许非管理员调用**；关闭＝仅管理员可用。管理员始终可用 |
| `permission_denied_message` | `抱歉，只有管理员才能使用语音功能哦~` | 仅管理员模式下对非管理员的提示 |
| `non_admin_cooldown_enabled` | `true` | 非管理员单句冷却开关 |
| `non_admin_cooldown_seconds` | `3` | 非管理员单句冷却秒数 |
| `non_admin_cooldown_message` | `说得太快啦，请 {remaining} 秒后再试~` | 触发冷却的提示 |
| `non_admin_limit_enabled` | `true` | 非管理员限额开关 |
| `non_admin_limit_window_seconds` | `60` | 限额窗口秒数 |
| `non_admin_limit_count` | `10` | 窗口内最大句数 |
| `non_admin_limit_message` | `你 {window} 秒内已用满 {limit} 句啦，请 {remaining} 秒后再试~` | 触发限额的提示 |

## 依赖

- AstrBot 环境已包含 `aiohttp`。
- 需要先启动 `live-stream-chatbot` 中间件（`npm start`）；genie server 未运行时中间件会自动拉起（`.venv-genie`），首条请求可能较慢。
- 修改本插件代码后需在 AstrBot WebUI 重载插件（或重启 AstrBot 容器）生效。

## 变更记录

- **v1.4.0**：命令前缀改回 `/`——移除 `#` 写法，新增对「唤醒前缀被 AstrBot 剥离后的无前缀形态」的识别（`角色说 文本`），`/角色说` 与 `/tts`、`/语音` 均可用。
- **v1.3.0**：权限模型简化为单一开关——默认仅管理员可用，`allow_non_admin` 放开给其他用户（默认 `false`）；移除语义重叠的 `enable_permission`、`admin_only` 与 `non_admin_disabled_message`。
- **v1.2.0**：新增管理员权限控制与非管理员冷却（默认 3 秒）、限额（默认 1 分钟 10 句），数字与提示文案均可配置。
- **v1.1.0**：新增 Genie 情绪标签支持。
